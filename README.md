# Nessa extensions

Nessa's first-party extensions. Each one is an MCP server that ships its own
interactive UI as an [MCP App](https://github.com/modelcontextprotocol/ext-apps)
(`io.modelcontextprotocol/ui`), so it works in [Nessa](https://github.com/nessalabs/nessa-agent)
and in any other host that supports MCP Apps.

The repository is being set up in
[#1](https://github.com/nessalabs/nessa-extensions/issues/1).
